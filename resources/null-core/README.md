# Null Core

**Version:** 1.0 (0 KB, all of it verified)
**Requirements:** none — and none is also what it delivers
**Compatibility:** everything, including itself

Null Core is a dependency mod consisting of this README and nothing else. It contains
no plugins, no assets, no scripts, and no executable code. Its install footprint is
zero kilobytes, and its runtime footprint is the same zero, maintained with the same
discipline PEF applies to its own.

## What it does

Nothing. That is the entire specification, and it is met in full.

## Why it exists

Placebo Engine Framework refuses to load without it. This feature is called
**Dependency Integrity**. PEF could simply have loaded without any dependencies at
all, but then users would have had no opportunity to download something, extract it
incorrectly, and file a support ticket — and a modern modding experience without at
least one of those steps is not a modern modding experience.

## Installation

1. Extract this folder to `Data/NullCore/` so that this file exists at:
   `Data/NullCore/README.md`
2. That's it. There is no step 2. There was never going to be a step 2.

## FAQ

> **Q: My game performs exactly the same with or without this.**
> A: Correct.

> **Q: Is it safe to remove?**
> A: Removing it disables PEF, which also changes nothing. The choice is yours, and
> the outcome is not.
